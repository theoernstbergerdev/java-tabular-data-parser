# 📊 Java Tabular Data Parser

A simple Java project focused on **2D arrays, input validation, and basic data analysis**. 
The program stores information about four people and performs salary-related calculations 
using fundamental Java programming concepts.

## 🚀 Features

* 📝 **Data Entry:** Register each person's ID, age, and salary.
* 🛡️ **Input Validation:** Ensure ages are between 0 and 110.
* 💰 **Highest Salary:** Identify the highest salary recorded.
* 💵 **Lowest Salary:** Identify the lowest salary recorded.
* 📈 **Average Salary:** Calculate the average salary of all registered people.
* 👥 **Above-Average Count:** Count how many people earn more than the average salary.

## 🛠️ Technologies

* **Java** — Core programming language.
* **Scanner** — User input handling.
* **2D Arrays** — Tabular data storage.
* **For Loops** — Data entry and iteration.
* **Enhanced For Loops (`for-each`)** — Simplified data traversal.
* **Conditional Statements** — Data analysis and validation.

## ⚙️ How It Works

The program stores information in a two-dimensional array with four rows and three columns.

| Column | Data   |
| :----- | :----- |
| `0`    | ID     |
| `1`    | Age    |
| `2`    | Salary |
